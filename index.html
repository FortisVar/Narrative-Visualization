Titanic Narrative Visualization

Narrative Overview

This website is dedicated to exploring, analyzing, and visualizing the statistics of the passengers on the Titanic. The link to the raw Titanic.csv file can be found either on this projects github or the file's original source:
Github: here
Source: here

Each scene will focus on a specific trend when analyzing the dataset with a certain perspective. At the end of the narrative there will be options to further filter the data to explore it in more depth.

This scene displays the distribution of the total number of passengers, survivors, and deaths on the Titanic. The area of each circle correlates to the respective statistic.

Overview Graph

Hover over any circle to see details

Survivors and Deaths by Gender

In this scene we can see a stacked bar chart showing the number of survivors and deaths for everyone, males only, and females only. Compared to each other we can see that proportionally that more males died than females. This may have been due to the fact that women and children were first to be evacuated.

Gender Graph

Hover over any bar to see details

Survivors and Deaths by Class

In this scene we can see a stacked bar chart showing the number of survivors and deaths for each class of ticket for the Titanic. This Graph demonstrates that the better class ticket a passenger had the more likely they were to survive. This is likely due to the fact that first class passengers were closer to lifeboats and were closer to the upper deck, while lower class tickets were further from the upper deck.

Class Graph

Hover over any bar to see details

Survivors and Deaths by Age

In this scene we can see a stacked bar chart showing the number of survivors and deaths for each age bin for the Titanic. In this graph the correlation of age and survival is a weaker metric, however trends can still be derived from the data. Younger groups seemed to have a better rate of survival than older groups.

Age Graph

Hover over any bar to see details and adjust the slider to change the bin size

Survivors and Deaths per Passenger

In this scene we can see specific people, their information, and if they survived. This graph puts in to perspective the survivors and deaths on the Titanic. This graph will later be able to be filtered to focus different groups of passengers.
